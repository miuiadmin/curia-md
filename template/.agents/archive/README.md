# archive/ — 冻结留档区

**装什么**：类型化文档的冷历史（`plans/`、`research/` 及 `skills/` 下的 runbook）。**只归档、不删除。**

**不装什么**：笔记的归档——它们走 [../notes/archived/](../notes/archived/)（另一处归属）；`SKILL.md` 与各家 README 是活的入口页，不归档。

## 归档四步

1. **移动**：文档移入本目录（可加品类子目录）；笔记移入 [../notes/archived/](../notes/archived/)（扁平放置）。
2. **加行**：头块末尾加 `Archived: yyyy-mm-dd`；原有 `Type:`、`Status:` 保留，作为它退役前的身份。
3. **重写自身相对链接**：逐条按目标归档后的位置重核——加品类子目录时深了一层，上行链接各补一层 `../`，同级链接对未同批归档的目标失效；平铺时深度不变，上行链接大体照旧，须改的是同级链接与指向同批归档件的链接。漏改时目标若仍存在会静默改指：加子目录时 `../README.md` 从 `archive/plans/` 解析到 `archive/README.md`，平铺时同级 `README.md` 从 `archive/` 解析到同一处。
4. **修入链**：全仓扫描指向旧路径的相对链接，同批改到新位置：

```bash
rg -n '\]\([^)]*<目标文件名>' .agents/ docs/
```

**第三步不能省。** 不重写就会出两类事故。其一，当场失效：链接没改到新位置、目标已不在解析处——组 3（链接）覆盖归档区，必报。其二，更隐蔽的一类——静默指错：漏改的链接仍解析到一个**存在**的文件（加子目录时 `../README.md` 解析到 `archive/README.md`，平铺时同级 `README.md` 也解析到它），机器全绿而指向已错。

## 检查与冻结

- 归档区不是豁免区：检查器对归档件查链接可达（组 3），对带类型头块的归档件另查 `Archived:` 行（组 1 的一部分）（这正是四步第 3、4 步与类型化文档第 2 步的机器验证面）；其余判据不查归档件——冻结件永不修改，查出来也无法处置。
- 归档件永久冻结：不编辑、不翻译、不重排、不移动、不删除；它不再是对当前行为的权威，仅作历史快照。冻结靠纪律与评审，机器不做哈希封印。

## 为什么不是删除

「做完了就不用了、但回顾时可能还会看」是常态需求。归档 = 可发现的历史；删除 = 丢失上下文。**当不确定时，归档。**
