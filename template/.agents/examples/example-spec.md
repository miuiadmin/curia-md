# 导出接口规格

Type: spec
Status: done
Updated: 2026-03-14

一句话说明：本文约束导出接口的请求、响应与错误语义，供调用方与实现方共同引用。

## 背景

导出能力最初由三个脚本各自实现，字段与错误码互不一致。本文把三方对齐后的契约落成成文规格，调用方与实现方都以本文为准。

## 范围

- 覆盖：导出的请求字段、响应结构、分页、错误码与幂等语义。
- 不覆盖：导出任务的调度与存储（归运维手册）、文件格式渲染（归实现方文档）。

## 契约

| 名称 | 类型/取值 | 必填 | 语义 |
|---|---|---|---|
| `format` | `csv` / `json` | 是 | 输出格式；同一查询两种格式的字段集必须一致。 |
| `since` | ISO 8601 时间戳 | 否 | 只导出该时刻之后的记录；缺省为全量。 |
| `page` | 正整数 | 否 | 从 1 开始；缺省为 1。 |

- 幂等：同一请求重复调用返回同一结果，不产生重复记录。
- 错误码：`400` 参数非法、`404` 目标不存在、`429` 请求过频（带 `Retry-After`）。

## 验收标准

- `curl -s '<endpoint>/export?format=json&page=1'` 返回的条数与分页大小一致。
- 把 `format` 改成非法值，响应状态码为 `400` 且错误体含 `code` 字段。

## 适用边界

本文不承诺导出延迟；超大时间范围的分页上限由实现方配置，超出时返回 `400` 而不是静默截断。`Status: done` 后本文仍是长期权威，变更原地修改并更新 `Updated:`。
