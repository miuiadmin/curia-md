# docs/ — 外部事实与知识

本目录收录仓外系统的登记与定义：资源 ID、字段映射、端点、协议、台账与记录。**当前版即唯一真相**——改了直接改，历史在 git。

## 约定

- 无头块、无状态机；不写计划、决策因果与原始证据包——那些归 `.agents/` 的家（见[规范全文](../.agents/README.md)）。
- 文件名用 kebab-case 主题名、不加日期前缀——身份是主题，不是落笔时点。
- 引用一律相对 Markdown 链接；指向 `.agents/` 时写 `../.agents/…`。
- 本目录按需创建；不启用它也不影响 `.agents/` 完整使用。
